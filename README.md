# 智能叶菜洁净化包装设备项目展示与询价管理系统 V1.0

面向大学生创新创业训练计划比赛展示的前端项目，用于介绍智能叶菜洁净化包装设备方案，并提供预约演示、询价意向提交和本地模拟后台查看能力。

当前版本是纯前端演示系统，数据通过浏览器 `localStorage` 保存，适合本地演示、项目汇报和后续资料整理。

## 项目定位

- 比赛展示：集中展示项目背景、设备方案、结构说明、技术参数、应用场景和团队信息。
- 本地演示：通过表单和 `/admin` 页面模拟咨询数据提交与管理流程。
- 阶段原型：为后续接入真实后端、完善文档和部署上线保留清晰的前端结构。

## 主要功能

- 首页项目展示，包括 Hero、痛点分析、方案说明、设备结构、样机图片、创新点、技术参数、应用场景、成果和团队信息。
- 预约演示表单，提交后写入当前浏览器本地数据。
- 询价意向表单，提交后写入当前浏览器本地数据。
- `/admin` 本地模拟后台，可查看、搜索、筛选、刷新、清空和导出 CSV。
- 静态内容集中维护在 `src/data`，便于后续替换真实数据和整理材料。

## 技术栈

- React 18
- Vite 5
- TypeScript
- Tailwind CSS
- React Router
- Browser localStorage

## 本地运行

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

访问终端输出的本地地址，通常为：

```text
http://localhost:5173/
```

## 构建预览

生产构建：

```bash
npm run build
```

本地预览构建产物：

```bash
npm run preview
```

构建产物输出到 `dist` 目录。

## Vercel 部署

本项目可以作为 Vite 静态前端项目部署到 Vercel。

推荐配置：

- Framework Preset：Vite
- Build Command：`npm run build`
- Output Directory：`dist`
- Install Command：`npm install`

项目使用 React Router 的前端路由，已通过 `vercel.json` 将访问请求回退到 `index.html`，用于支持部署后直接访问 `/admin`。

## 项目结构

```text
src
├── app                 # 应用入口与路由
├── components          # 通用组件、表单组件、后台组件和布局组件
├── data                # 项目静态展示数据
├── pages               # 页面级组件
├── sections/home       # 首页展示区块
├── styles              # 全局样式
├── types               # TypeScript 类型定义
└── utils               # localStorage、CSV、校验等工具函数
```

## 演示后台说明

访问路径：

```text
/admin
```

`/admin` 是本地模拟后台，不连接真实服务器。页面读取当前浏览器中的预约演示和询价意向数据，支持关键词搜索、类型筛选、刷新、CSV 导出和清空本地记录。

后台数据只存在于当前浏览器。更换浏览器、清理浏览器数据或更换设备后，数据不会自动同步。

## 当前版本限制

- 不接入真实后端。
- 不使用数据库。
- 不包含真实登录、权限控制、支付或客户系统。
- 表单数据仅用于本地演示，保存在当前浏览器 `localStorage`。
- `/admin` 不是生产后台，不具备多用户协同和服务端数据管理能力。
- 未确认或未实测的数据继续使用“待实测”或 `TODO` 标注，不虚构真实参数、成果或团队信息。
